# Food Ordering System (Requirements)

## Problem Statement
    Most small business are still using manual processes for handling orders for their product, which may lead to problems in tracking orders,
    recording payments, and managing stock. Customer are also faced with difficulties when viewing products and making orders without a central
    system.
## User Personas
### Admin
- Manage Menu Items 
- Views all customer orders
- Monitors Payment (Cash/Online Payment)
- Manage Users

### Customer
- Sign up and Log in
- Browse Food 
- Place order in Add to cart
- Makes Payment
- Views order history

## User Stories
1. As a customer, I want to create an account so I can order food
2. As a customer, I want to log in so I can access my order history
3. As a customer, I want to view the menu so I can choose whatever I want.
4. As a customer, I want to place order to my add to cart then i can order multiple all at once
5. As an admin, I want to manage the prices and availability so that the menu can be accurate
6. As an admin, I want to confirm payments so that orders can be mark as completed

## Acceptance Criteria
### User Story Number 3: Customer views food menu
Done when: 
- The system displayed the available food items.
- Each item shows name, price, description, and images.
- The page loads without Error

### User Story Number 5: Admin Manage Menu Items
Done when:
- The System displayed all food items
- Each Items can be delete and edit which may also set as "available" and "Not Available"
- The updates pushed through without Errors
